# neckfors.github.io

My hub page: **https://neckfors.github.io**

It lists my public apps and games automatically. Any public repo with GitHub Pages turned on shows up as a row that opens the live app. Repos with the topic `game` go under Games, everything else under Apps. Forks, archived repos, repos with the topic `hidden` and this repo are left out. No edits are needed when I add a new app.

Plain HTML, CSS and JS, no build step. One column: Games first, then Apps. Each row has small labels: "Web" (opens the live app), plus "Phone" when the app has an install file (manifest), found automatically (except Type Blaster, listed in `NO_INSTALL` in app.js). Repos with the topic `apk` also get an "APK" label that opens the newest release, where the Android app is downloaded. A slow dark gradient background, a still gradient title, and simple hover effects. Works on phones.
