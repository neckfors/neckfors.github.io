# neckfors.github.io

My hub page: **https://neckfors.github.io**

It lists my public apps and games automatically. Any public repo with GitHub Pages turned on shows up as a card with an Open button (the live app) and a Code button (the repo). Forks, archived repos and this repo are left out. No edits are needed when I add a new app.

Plain HTML, CSS and JS, no build step. Follows the device's light or dark setting.
