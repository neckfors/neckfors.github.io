# neckfors.github.io

My hub page: **https://neckfors.github.io**

It lists my public apps and games automatically. Any public repo with GitHub Pages turned on shows up as a row that opens the live app. Repos with the topic `game` go in the Games column, everything else in Apps. Forks, archived repos and this repo are left out. No edits are needed when I add a new app.

Plain HTML, CSS and JS, no build step. Animated gradient background with floating bubbles, hover effects on every card (turned off for people who prefer reduced motion). Each app is one row; tapping it opens the app.
